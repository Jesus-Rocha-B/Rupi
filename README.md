# RUPI

RUPI es una plataforma de aprendizaje digital en desarrollo para estudiantes de primaria de colegios públicos del Perú. Su propósito es ayudarles a reforzar lo aprendido en clase con actividades interactivas, recorridos gamificados y acompañamiento cercano mediante inteligencia artificial.

El gallito de las rocas inspira a Rupi, el personaje que guía la experiencia. Las rutas también conectan los contenidos escolares con lugares, expresiones y situaciones del Perú para que aprender se sienta más cercano a la vida cotidiana de los estudiantes.

## Ejecutar en local

Necesitas Node.js y npm instalados.

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
npm run preview
```

Para revisar el código con ESLint:

```bash
npm run lint
```
